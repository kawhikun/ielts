v66.15 按题型智能放原文版

题目 + 按题型匹配的原文证据先给用户：段落标题/主旨题给整段，段落信息匹配题给定位段落，细节/填空/判断题给完整证据句，听力题给含答案的完整话轮。用户填写答案后，再出示正确答案、解析、同义替换和 OCR 原题页截图。

总的考场做题流程

阅读流程

  1. 先看题型分布：标题题、段落信息题优先建立段落大意。
  2. 边做概括题，边把穿插的信息题定位词（人名、数字、专有名词、否定、比较级）标到对应段落。
  3. 填空题先看空格前后，预判词性、单复数和字数限制，再回原文找同义替换。
  4. 判断题只看题干与证据句：同义为 TRUE/YES，矛盾为 FALSE/NO，原文没说为 NOT GIVEN。
  5. 最后处理难题，不在单个细节题上耗时。

听力流程

  1. 听前先预判场景、说话人关系和答案类型（数字、地点、人名、名词、形容词、字母）。
  2. 圈定位词和限制条件，预判同义替换、干扰项和可能的更正。
  3. 听中跟随题号顺序，重点抓转折、否定、纠正、拼写、数字和单位。
  4. 听后复查词性、拼写、单复数、大小写和字数限制。

原文应该怎么放：v66.15 统一规则

段落标题 / 段落概括题

放目标段落全文。这类题判断的是整段主旨，不能只截一句。

段落信息匹配题

放答案所在段落或 section 全文。用户需要确认该信息是否真的出现在这一段。

细节 / 判断 / 填空题

放能直接推出答案的完整句；如果代词、转折或比较关系不够清楚，再补相邻一句。

听力题

放含答案的完整听力原文句或完整话轮；有纠正、否定、转折时保留前后一句。

练习卡片

默认只显示可练卡；需要排查乱码/OCR问题时，可切换“只看需复核卡”。OCR 原题页截图放在答案和解析后面。
