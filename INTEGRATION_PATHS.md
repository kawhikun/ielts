# 整合路径

主站包直接放 GitHub Pages 仓库根目录。

题卡路径：

```text
assets/data/cards_cambridge_reading.json
assets/data/cards_zyz_reading.json
assets/data/cards_cambridge_listening.json
assets/data/cards_highfreq_listening.json
assets/data/manifest.json
```

音频小包解压到同一个仓库根目录，不要改层级。最终路径示例：

```text
assets/audio/cambridge/book16/test1/section1.mp3
assets/audio/cambridge/book20/test4/section4.mp3
assets/audio/highfreq/P1/p1-asia-pacific-tours-activity-holidays/audio.mp3
assets/audio/highfreq/P4/p4-canadian-maple-syrup/audio.mp3
```
